# Assignment 10 — Budget Tracker

Источник: `anotherhw.zip`, папка `budgettracker`. В архиве задание представлено четырьмя скриншотами; ниже текст собран по ним. Служебные подсказки курса (TodoList, Material UI, DataGrid и React Router) не являются отдельными заданиями, а обозначают технологии, которые нужно освоить перед выполнением шагов.

## Цель

Создать приложение Budget Tracker на React и TypeScript, которое позволяет добавлять доходы и расходы, удалять записи, видеть баланс и статистику.

## Шаг 1 — базовая версия (3 балла)

1. Использовать React и TypeScript.
2. Создать компонент `BudgetTracker` с полями:
   - Description — строка;
   - Amount — число;
   - Type — `Income` или `Expense`;
   - Date — дата.
3. Все поля должны быть заполнены. Сумма должна быть числом, не пустой, не `NaN` и не отрицательной.
4. Расход сохраняется как отрицательная сумма.
5. Создать отдельный компонент `BudgetItems`, который показывает таблицу с описанием, суммой и датой. У каждой строки должна быть кнопка удаления.
6. Список записей и обработчик удаления передать в `BudgetItems` через props.
7. Подключить `BudgetTracker` в `App`.

Бонус шага: показать текущий баланс и добавить месячный лимит с предупреждением о превышении.

## Шаг 2 — Material UI (3 балла)

Создать ветку `step2` и:

- добавить Material UI;
- сделать `AppBar` с заголовком Budget Tracker;
- заменить поля и кнопки на подходящие Material UI-компоненты;
- выровнять поля по горизонтали и добавить отступы;
- использовать MUI-X `DatePicker`;
- отображать даты в формате `yyyy-mm-dd`.

## Шаг 3 — DataGrid (3 балла)

Создать ветку `step3` и заменить HTML-таблицу на MUI-X `DataGrid`.

В таблице нужны столбцы Title/Description, Amount и Date. Таблица должна поддерживать сортировку, фильтрацию и пагинацию.

Бонус шага: выделить расходы красным, доходы зелёным и добавить группировку по типу (в базовой бесплатной версии DataGrid группировка может быть представлена фильтром/сводными метками по типу).

## Шаг 4 — маршрутизация (3 балла)

Добавить React Router:

- `Home` — приветственная страница;
- `BudgetTracker` — страница ввода и списка;
- `Statistics` — страница общей суммы доходов, расходов и saldo;
- навигацию между страницами;
- состояние записей поднять в `App`, чтобы оно сохранялось при переходе между маршрутами.

## Критерии проверки

- пустая или некорректная форма не добавляет запись и показывает понятную ошибку;
- расходы имеют отрицательное значение, доходы — положительное;
- удаление строки действительно убирает её из списка;
- после перехода на Statistics ранее добавленная запись остаётся доступной;
- проект запускается командой `npm run dev` и собирается командой `npm run build`.
